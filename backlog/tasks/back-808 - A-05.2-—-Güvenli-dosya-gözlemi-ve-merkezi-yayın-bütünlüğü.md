## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Ham guarded envanter task/draft/document/decision/milestone/config ve arşivleri kapsar; eksik yolu yalnız tam güvenli taramada silme sayar. Parser hatası, okunamayan veya kararsız yol trusted checkpointi korur ve ilgili projenin yazısını OBSERVATION_UNAVAILABLE ile durdurur. İlk A-05 taraması eski A-04 dış olaylarını üretmeden baseline olur; restart/offline farkları source=external, actor=unknown, occurredAt=null, detectedAt=scan zamanı tek olaydır.
Merkezi koordinatör recovery sonrası aynı proje kuyruğunda startup, her API girişi, backlog watcher ve 30 saniyelik kontrolü birleştirir. Central ContentStore/config watcher diskten erken yayın yapmaz; observer commit sonrası exact snapshot cache/search/WS’ye verilir. Bozuk Markdown sırasında sağlam liste/search son güvenli görüntüyü korur; değişmiş spesifik detail 503 verir, unsafe boundary A-03 gereği hard503 kalır. Managed finalize STORE gözlem checkpointini aynı transactionda güncellediği için self-echo tarihçe üretmez. Agent actor yazımları source=agent olur; task editArgs mevcut ortak builderı, task create documentation/ordinal ve decision JSON status mevcut Core yollarını kullanır.
