## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
@codex-web MCP contribution: `src/mcp/connected.ts` adds a fixed-project stdio adapter using the shared ServerClient, with the existing task, document, milestone, Definition of Done and workflow tool names and schemas. Server-mode writes require the revision read from the record; operationId is optional for an explicit same-key retry. Task edit sends `{editArgs}`; create maps acceptance criteria and task DoD into the HTTP payload. DoD defaults are read from live config, while config write is an explicit unsupported tool error. Workflow resources explain fixed project roots, revisions, uncertain outcomes and forbidden admin/config mutations. `src/commands/mcp.ts` selects this adapter before local root/Core resolution when connection flags are present; an incomplete connection fails without local fallback. Agent key secret stays in the key file and never enters tool output. Scoped adapter tests passed 3/3 with 49 assertions; real SDK StdioClientTransport calls against a temporary loopback HTTP stub passed 1/1 with 9 assertions, including fixed roots and no local backlog creation. Native compiled/full acceptance remains with BACK-812.

Tek ServerClient, açık bağlantı bayraklarını yerel root/config migration öncesi seçer; hata local dosyaya düşmez. Mevcut etkileşimsiz task/draft/doc/decision/milestone, config read/history/operation, ortak fuzzy search ve JSON çıktısı bağlı. JSON watch mevcut watchJson ile polling/backpressure/parent yaşam döngüsünü kullanır. Aynı okuma revisionı ve UUID; lost network/body yanıtı yalnız operation requestHash gönderilen canonical hash ile eşleşirse kabul edilir. Reused UUID + farklı body ve pre-delivery network failure eski sonucu başarı göstermez; lookup401/403 oluşsa da operation ID korunur.
