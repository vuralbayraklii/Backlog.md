## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Mevcut BacklogServer API eşlemesini tek kaynaktan kullanılabilir hale getir; merkezi dinleyici proje kimliğini SQLite kaydından çözsün ve aynı işleyiciyi ilgili Core bağlamına bağlasın. HTML ve proje metaverisi içerik taramasını beklemesin.
2. Merkezi Core politikasında dal birleştirme/uzak fetch, otomatik commit ve durum komutlarını kapat; bu seçimi proje yapılandırması ve HTTP girdisinden bağımsız tut.
3. server --data-dir start komutunu 127.0.0.1:6420 varsayılanı, isteğe bağlı --open ve açık port/veritabanı hatalarıyla ekle. WebSocket ve ekleri proje kimliğiyle ayır; kapanış kaynaklarını temizle.
4. İki örnek proje ile API, bildirim, hata ve yerel browser regresyon testlerini çalıştır; tip/Biome/build ve derlenmiş sunum kontrolleriyle kanıtı kaydet. Sadelik incelemesi ve devir notunu güncelle.
<!-- SECTION:PLAN:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Merkezi sunucu tek 127.0.0.1 dinleyicisinde BacklogServer API eşlemesini yeniden kullanır. Kayıtlı kimlik SQLite üzerinden çözülür; proje başına Core/içerik/arama/izleyici/WebSocket grubu ihtiyaçta açılır. Core serverMode, ayar dosyasından bağımsız olarak dal/uzak fetch, otomatik commit ve durum komutlarını kapatır. Altı yeni API testi 42 beklentiyle geçti; altı ilgili dosyada 66 yerel browser/CLI regresyonu geçti. Tip kontrolü 546 dosyada, yazmasız Biome 472 dosyada, build ve derlenmiş CLI yardımı geçti. Tarayıcı entegrasyonu ve tam derlenmiş HTTP kontrolü BACK-789 kapsamındadır.

BACK-789 doğrulaması sırasında aynı API grubuna taslak, kilometre taşı ve arama kapsamı; oluşturma/düzenleme/arşivleme dosya izolasyonu ve eşzamanlı stop/yeniden açma kontrolleri eklendi. Güncel src/test/central-server.test.ts: 8 başarılı, 59 beklenti. Bu ek kanıt verification/server/a01-3a-central-api.json içine işlendi.

Son sadelik/hata yolu incelemesi: kök yapılandırması okunabilir olsa da özel Backlog klasörü sonradan silinirse 503 dönülür ve klasör oluşturulmaz. Güncel merkezi API grubu 9 başarılı, 62 beklenti; verification/server/a01-3a-central-api.json güncellendi.
